Forecasts each GTA VI PlayStation 5 trophy's Exophase earn rate one week after launch. A pure-stdlib Python program fits each trophy's logit earn-rate trend against log time since release, shrinks the trend by fit quality, enforces story-chain and platinum monotonicity, and reports five honest quantiles per trophy.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
